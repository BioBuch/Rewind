# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.1.x   | Yes       |
| < 1.1   | No        |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities privately via **GitHub Security Advisories** (`Security` tab -> `Report a vulnerability`) in this repository. Include steps to reproduce, affected version, and impact. We will review and respond as soon as possible.
