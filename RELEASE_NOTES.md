# 🚀 Rewind v1.1 — The UI Overhaul Update! ✨

### 🎬 Brand-New Clip Playback Modal
- **Sleek Dark Surface Hierarchy 🖤**: Redesigned from the ground up with `#111216` surfaces, `#191b22` elevated controls, crisp `8px` corners, soft drop shadows, and a subtle top-edge glass highlight.
- **Edge-to-Edge Video Frame 🖼️**: Removed outer borders, header dividers, and mismatched side bands so your clips sit front and center, with a smooth `72px` bottom gradient scrim keeping controls readable over bright HUDs.
- **Minimal Player Controls 🎛️**: Borderless ghost buttons for Play/Pause, Mute, and Fullscreen, plus slim `2.5px` seekbar and volume tracks.
- **Cleaner Quick Trim ✂️**: Borderless waveform editor with a compact `28px` track and dimmed cut-out bars so your selected clip pops naturally.
- **Refined Action Bar & Navigation ↔️**: Borderless ghost pills for `Favorite`, `Copy Video`, `Discord 10MB`, and `Delete`, optically aligned with `Save Trim`, plus translucent floating `<` / `>` navigation arrows.

### 📚 Library Dashboard & Context Menu Refresh
- **Softer Borders & Crisp Contrast 🎨**: Replaced harsh outlines across cards, dropdowns, and filter pills with subtle `rgba(255, 255, 255, 0.08)` strokes and a high-contrast white active filter pill.
- **Snappier Right-Click Menu ⚡**: Translucent dark backdrop, softer shadow, tighter `9px` corners, rounded hover highlights, and a clean divider separating `Delete`.

### 🗂️ Cleaner Clips Folder
- **Hidden `.thumbnails` Folder 👻**: Automatically hides `.thumbnails` in Windows Explorer (`FILE_ATTRIBUTE_HIDDEN`) so your clips folder stays clutter-free.
